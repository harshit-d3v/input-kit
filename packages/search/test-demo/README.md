# @input-kit/search Demo

Test and demonstration files for the search package.

## Run the Demo

### Using the local server:

```bash
node serve.cjs
```

Then open http://localhost:3000 in your browser.

### Or open the HTML file directly:

Simply open `index.html` in your browser (some features may require a server).

## Test Imports

Verify all exports are working:

```bash
npx tsx test-imports.ts
```

## React Demo

The `demo.tsx` file contains a React component demonstrating package usage.

## Files

- `index.html` - Standalone HTML demo
- `demo.tsx` - React component demo
- `test-imports.ts` - Import verification script
- `serve.cjs` - Local HTTP server
- `README.md` - This file
